# Registros de decisiones arquitectónicas

Los ADR documentan decisiones tomadas desde la adopción de este sistema. No convierten inferencias sobre código heredado en decisiones aprobadas.

## Formato

Crear `ADR-NNN-titulo-breve.md` con:

- Identificador y título
- Fecha
- Estado: propuesto, aceptado, sustituido o rechazado
- Contexto y problema
- Alternativas consideradas (si se conocen)
- Decisión
- Justificación
- Consecuencias positivas y negativas
- Enlaces a código, issue o ADR sustituto

Añadir una entrada a [DECISION_LOG.md](DECISION_LOG.md). Una decisión aceptada no se reescribe para ocultar su historia: se marca sustituida y se enlaza la nueva.
