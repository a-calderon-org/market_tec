# Lista de verificación de auditoría

## Repositorio

- [ ] Estado, rama, commit y cambios preexistentes registrados
- [ ] Reglas `AGENTS.md` leídas
- [ ] Generados/dependencias excluidos del inventario sustantivo
- [ ] Manifiestos, CI/CD, entorno y documentación contrastados

## Backend

- [ ] Entradas, rutas, capas, validación y errores
- [ ] AuthN/AuthZ, CORS, secretos e inyección
- [ ] Datos, transacciones, concurrencia y migraciones
- [ ] Timeouts, reintentos, conexiones, logging y apagado
- [ ] Pruebas, lint, build y límites de ejecución

## Frontend

- [ ] Rutas, componentes, estado, formularios y API
- [ ] Carga, error, vacío y navegación
- [ ] Tokens, contenido no confiable y configuración pública
- [ ] Paginación, renderizado, recursos y tamaño
- [ ] Semántica, teclado, foco, labels y anuncios
- [ ] Unitarias, integración y E2E

## Integración y cierre

- [ ] Métodos/rutas/campos/respuestas comparados
- [ ] Autenticación, CORS y errores comparados
- [ ] Compatibilidad estática separada de verificación en ejecución
- [ ] Hallazgos con evidencia, impacto, recomendación y verificación
- [ ] Deuda priorizada por impacto, probabilidad, esfuerzo y dependencias
- [ ] Enlaces y contradicciones documentales revisados
